# Campus Lost and Found

A web-based Lost and Found Management System for our campus, built with HTML, CSS, JavaScript, PHP and MySQL.
Students, teachers and school personnel can report lost items, post found items, search listings and claim items.

## Folder guide

| Folder | Purpose |
|---|---|
| `docs/` | Project documents: blueprint, diagrams, changelog |
| `sql/` | Database files (schema and sample data) |
| `config/` | Settings: database connection and constants |
| `src/` | Logic: PHP functions for login, items, claims, uploads (all SQL lives here) |
| `templates/` | Shared page pieces: header, footer, navigation |
| `public/` | Website pages opened in the browser |
| `public/assets/css/` | Stylesheets |
| `public/assets/images/` | Logo, hero and sample item photos |
| `uploads/` | Photos uploaded by users |
